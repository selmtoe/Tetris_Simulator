# 学習データの収集と再学習（ppt-train）

## 全体の流れ
```
webdata（24本・2,012試合の start/end/winner）
   ↓ mine.py        1本ずつDL → 結果画面を自動検出 → フレーム保存 → いまのモデルで不一致を記録
   ↓ synth_draws.py 2P勝ちの左半分 ＋ 1P勝ちの右半分 ＝ 両者ばたんきゅー（引き分け）を合成
   ↓ build_dataset.py 既存データ＋新規をハードリンクで束ねる（scene10 / end3）
   ↓ train_model.py  画像から直接学習 → ONNX 書き出し
   ↓ evaluate.py     ホールドアウト動画で勝敗一致率を測る
   ↓ viewer.py       単体HTMLで一覧・確認（Labとは無関係）
```

## ファイル
| ファイル | 役割 |
|---|---|
| `mine.py` | 結果画面の検出（最後の暗転の直前3.4秒）とフレーム抽出、補正候補の記録 |
| `synth_draws.py` | 引き分け合成（結果画面の後半から半分割） |
| `build_dataset.py` | 学習用データセットの組み立て（`--exclude` でホールドアウト除外） |
| `train_model.py` | 軽量トレーナー（クラス重み付き、動画単位でtrain/val分割、ONNX出力） |
| `evaluate.py` | フレーム単位・試合単位（多数決）の勝敗一致率 |
| `viewer.py` | `dataset/viewer.html` を生成（カテゴリ絞り込み・拡大・ラベル修正メモ） |
| `collect.py` | （旧）固定窓での収集。いまは mine.py を使う |
