## v81 の中身
- 時間指定の解析 `TR_SEGMENT_WINDOW="開始秒,終了秒"` を追加。シーン検出は動画全体を見たうえで、開始がその範囲にある試合だけを解析し、1から番号を振り直す。動画を切らないので時刻は元の動画のまま。PPT Lab は `%LOCALAPPDATA%\PPTLabnalysis-ranges.json`（{"YouTube動画ID": [開始秒, 終了秒]}）から渡す。指定がなければ v80 と同じ。
- 確認（REGRESSION-LOG `v81-segment-window-b`）: vsたわ 56試合で v80 と全手同一、警告0・検証エラー0。

## v80 の中身
- 解き直し（修復ラダー）で試すおじゃまの段数の上限を 8段 から 12段 に広げた。_ySYK #89 は T-spin ダブルの直後に10段せり上がり、その一番上の行（穴が4列目）を次の縦 I が消していた。消えた行はアニメーション中にしか映らず9段と読まれ、10段は上限の外で試されていなかった。`TR_GARBAGE_BACKTRACK_MAX_LINES` で上書きできる。
- 確認（REGRESSION-LOG `v80-gmax12`）: 計256試合で v79 と全手同一、警告0・検証エラー0。_ySYK #89・XTveY #89 とも警告なし。

## v79 の中身
- 大量のおじゃまのせり上がりで積みがフィールドの上にはみ出すと、通常の出現位置（3段分）が全部ふさがり、正しい手順に合法な出現がなくなっていた。そのため解き直しが偽のライン消去を選んでいた（XTveY #89、9段せり上がり直後）。
- v79 は、出現位置が全部ふさがり、かつ盤面が80マス以上埋まっているときだけ、さらに最大4段上での出現を許す（`TR_SPAWN_EXTRA_ROWS`）。この処理は**すでに問題が出ている選手の解き直し（修復ラダー）の中だけ**で動く。問題のない試合は v78 と同じ計算になる。
- 確認（REGRESSION-LOG `v79-ladder-spawn`）: vsたわ 56・bTL5 前半72・15先 前半69・最高3300 前半59 の計256試合で v78 と全手同一、警告0・検証エラー0。XTveY #89 は警告なしになった。

## v78 の中身
- シーク先が H.264 の IDR でないキーフレーム（回復点つき I フレーム）だと、NVDEC が次の IDR まで 2〜5 秒のコマを捨てていた。試合開始がその直後だと最初の5〜6手が抜けた（10ell5 1/94、XoaWL 25、XTveY 132）。v78 は IDR でない着地なら 1・2・4… 秒ずつ戻して IDR から読む。`TR_SEEK_IDR=0` で旧動作。
- 確認（REGRESSION-LOG `v78-seek-idr`）: vsたわ 56・bTL5 前半72・15先 前半69・最高3300 前半59 の計256試合で v77 と全手同一、警告0・検証エラー0。同じ動画で v77 と比べて変わったのは上の4試合だけ。

## v77 の中身
- v76 の「NEXT が動いた時刻から開始」の探す範囲を **GO が消えた時刻の前後1秒** に固定し、開始を GO 終わりより前にずらすことも許した。
  v76 は READY を GO と数えると探す範囲が最初の手に届かず（bTL5 49）、NEXT が GO 終わりより前に動くと使われなかった（uRZn 52/54/66/69）。
- 確認（REGRESSION-LOG `v77-queue-move-window-b`）: vsたわ 56試合 警告0・検証エラー0・変化 1/8210手。bTL5 前半72試合 v76 と同一。15先 前半69・最高3300 前半59 で警告0（v76 の 52/69 の警告が消え、54/66 の最初の1ミノの取りこぼしが戻った）。

## v76 の中身
- v75b（おじゃまの上昇の誤検出を穴の並びで却下）に、**開始時刻を「GO の後で HOLD/NEXT の枠が最初に動いたフレーム」にする**修正を足したもの。
  GO が消えた時刻は最初のミノが出る 3〜8 フレーム前で、速い最初の1手や HOLD を取りこぼしていた。
  `TR_QUEUE_MOVE_START=0` で従来の開始に戻る。

## 確認済みのこと（REGRESSION-LOG `v76-queue-move-start`）
- vsたわ 56試合: 警告 0・検証エラー 0（v75b から 93/8264 手が変化。開幕で抜けていたミノが入る）。
- しゃけごはん（FMhM）前半51試合: 警告 2→0、盤面のずれが続く試合 5→0、開幕の取りこぼし 12人→1人。
- てとぼ（bTL5）前半72試合: 盤面のずれが続く試合 1→0（試合49 が直った）。
- 全23スイートでの確認はしていない（利用者の判断で省略）。

## 使い方
- 1ファイル版は `Tetrace-V1.0-PPT.zip`（中身は同じ）。
- 実行は `run.ps1`。環境変数もそこで設定する。エンジンは `tetris.onnx` と同じフォルダの `next_hold.onnx` を読む。
- CUDA などの DLL（約1.4GB）はモデルに含めない。`tools/video-recovery-runtime/bin` を使う。
