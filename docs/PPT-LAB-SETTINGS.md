# PPT Lab 設定画面 最終設計（2026-10-29 確定）

## 0. 決定事項

- ナビは Videos / Tetofu / Tags / Settings のまま。**データ管理は Settings 内のタブ**にする。
- Settings のタブ: **一般 / 表示 / 解析 / 名前とタグ / データ管理**
- 削除した項目: シミュレータ既定URL、外部ツール、解析するプレイヤー、名前画像の大きさ、同時解析本数、起動時の「名前確認の続き」、バックアップと復元
- 「追加したら自動で解析」は**常にオン**（設定に出さない）

## 1. 一般

| ラベル | キー | 型 | 既定 | 選択肢 |
|---|---|---|---|---|
| 起動時に開く画面 | `startView` | enum | 動画一覧 | 動画一覧 / 前回の画面 |
| リンクの開き方 | `openLinks` | enum | 新しいブラウザ | 新しいブラウザ / このウィンドウ内（準備中） |
| 解析完了の通知 | `notifyAnalysis` | bool | オン | オン / オフ（アプリ内トーストのみ） |
| 保存時にタグ選択を出す | `tagPromptOnSave` | bool | オン | オン / オフ（直近のタグを引き継ぐ） |

## 2. 表示

| ラベル | キー | 型 | 既定 | 選択肢 |
|---|---|---|---|---|
| テーマ | `theme` | enum | ライト | ライト / ダーク |
| 1ページの件数 | `pageSize` | int | 40 | 20 / 40 / 60 / 100 |
| 既定の再生速度 | `playbackRate` | enum | x1.0 | x0.25 / x0.5 / x1.0 / x1.5 |
| 既定の並び順 | `sortOrder` | enum | 新しい順 | 新しい順 / 古い順 / 試合数が多い順 / 名前順 |

## 3. 解析

### 取得

| ラベル | キー | 型 | 既定 | 選択肢 |
|---|---|---|---|---|
| 画質の上限 | `downloadQuality` | enum | 1080p | 1080p / 720p / 480p / 320p |
| 動画の保存先 | `downloadDir` | path | データフォルダ | フォルダ選択 |

### 盤面認識

| ラベル | キー | 型 | 既定 | 選択肢 |
|---|---|---|---|---|
| 解析モデル | `analysisProfile` | enum | 標準 (1080p) | 標準 / 高速 (320p) / ぷよテト以外 / カスタム |
| 精度モード | `analysisDevice` | enum | GPU | GPU / CPU / 自動 |
| 解析の出力先 | `analysisOutputDir` | path | データフォルダ | フォルダ選択 |
| RAMディスクを使う | `useRamDisk` | bool | オフ | オン / オフ |
| 詳細ログを残す | `detailedLog` | bool | オフ | オン / オフ |

- 解析モデル・精度モードを変えると**次回は再解析**（画面に明記）

## 4. 名前とタグ

| ラベル | キー | 型 | 既定 | 選択肢 |
|---|---|---|---|---|
| プレイヤー名の記憶を自動適用 | `autoApplyNames` | bool | オン | オン / オフ |
| 自動タグを付ける | `autoTags` | bool | オン | オン / オフ |

## 5. データ管理（タブ）

### 5-1. プレイヤーネームの対応

- 画像・名前・使用回数・更新日を一覧（検索＋ページング）
- **解除**: 対応を削除（過去の保存名は残す）
- **名前の変更**: 対応名を書き換え
- **統合**: 別名を1つにまとめる（OCRの揺れ対策）

### 5-2. 動画の保存

| ラベル | キー | 型 | 既定 | 選択肢 |
|---|---|---|---|---|
| 動画ファイルの扱い | `videoStorage` | enum | 元の場所を参照 | 元の場所を参照 / アプリ内にコピー |
| 元ファイルが見つからないとき | `missingVideoAction` | enum | 警告を出す | 警告を出す / 自動で再取得 / 無視 |

- 動画の合計サイズ表示
- 使っていない動画の整理（試合0件・失敗）

### 5-3. キャッシュ

| ラベル | 操作 | 補足 |
|---|---|---|
| 名前画像のキャッシュを削除 | ボタン | サイズ表示。元動画から再生成できる |
| 解析キャッシュを削除 | ボタン | サイズ表示。次回は再解析になる |

### 5-4. このアプリについて

- バージョン / データの場所（表示のみ）
- DBサイズ・動画合計サイズ・試合数
- 設定のエクスポート / インポート（将来）
