# GA v1 — 相手盤面を参照する対戦用AI

通常画面の各プレイヤーのAI横にあるモデル名をクリックし、
「GA v1（相手盤面・対戦用）」を選択する。AIをONにして2Pで開始する。
人間相手、Cold Clear相手、GA同士のいずれも使用できる。
1PでGAをONにした場合は開始・リトライを案内付きで止める。
Cold Clearおよび人間操作の1Pには制限を加えない。

相手の40段盤面、HOLD、現在ミノ、公開NEXT、おじゃま予告を参照する。
画像認識で画面を撮影するのではなく、同じシミュレータ内のゲーム状態を受け取る。
未表示の未来ツモ、相手の内部探索、乱数seedは渡さない。
盤面・行動44係数と相手評価3係数。別NNや戦略切替はなく、Cold Clearの探索を再利用する。
操作中も現在の手の残りノード予算内で先読みし、確定・停止・リセットで止める。

採用モデル：`models/ga-v1.json`。
係数SHA-256：`880ded0208ae826e90546d4bb51c274f9f800068db3103a131fb7b5d367f49bd`。
追加学習・比較608試合で候補を比較し、元の採用個体を維持した。
同一3000追加ノード/手・10分上限・同一7bag・NEXT8の独立評価128戦は18勝92分18敗。
勝ち数だけでなく、勝ち1・引分0.5・負け0で評価する。
これは現在の公開版のNEXT10・実時間/操作中探索での勝率を保証する結果ではない。

公開版の既存Cold Clear WASMと機能は変更しない。
GA専用WASMの対応ソース・ビルド手順は
[`cold-clear-ga-source.zip`](../licenses/cold-clear-ga-source.zip) に収録。
このフォルダの `simulator.cjs` は本物のPlayerを使う検証用ハーネスで、Pagesには配布しない。
学習ログや個人データも配布しない。

検証：`node --test ai-lab/test-policy.cjs ai-lab/test-worker.cjs ai-lab/test-integration.cjs`。
