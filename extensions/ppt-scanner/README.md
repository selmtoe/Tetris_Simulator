# PPT Scanner 1.2.1

YouTubeのぷよぷよテトリスの動画から、現在のフレームをシミュレータの画像認識へ送ります。動画を目的の場面で一時停止し、拡張機能のアイコンを押してください。新しいシミュレータのタブに盤面・HOLD・NEXTが取り込まれます。既存のタブの局面は上書きしません。

## インストール・更新

Brave / Chromeの拡張機能管理画面でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」でこのフォルダーを選びます。既にこのフォルダーを読み込んでいる場合は、ファイルの更新後に対象の拡張機能の再読み込みボタンを押してください。同じフォルダーを使えば別の拡張機能を追加する必要はありません。

## 修正内容

- Hub内のシミュレータiframeにも画像を届けます。旧単独画面の受信関数にも対応しています。
- 動画を含むフレームを調べ、一度の操作につき送り先を一つだけ開きます。
- タブの読み込みと受信側の準備を待ちます。連打中は同じ取り込み処理を共有します。
- 動画がない・まだ読み込まれていない・取得が拒否された場合は、通知とアイコンの説明に原因を表示します。
- 個人用Labの `PPT_TRIGGER_SCAN` / `PPT_EXTENSION_DETECTED` 連携を維持します。Lab内のYouTube埋め込みも対象です。

従来のv2と同じ `activeTab` / `scripting` とホスト権限を使います。キャプチャはクリック時または対応するLabの操作時だけ実行し、画像を外部の解析サーバーへアップロードしません。認識は送り先のシミュレータ内で行われます。対象は標準の16:9のぷよテト対戦画面です。配信の独自レイアウトや動画の上に重ねられた表示は認識精度に影響します。

取り込み成功時は説明通知を表示しません。初回はシミュレータの認識モデルの読み込みに時間がかかる場合があります。

## 開発確認

リポジトリの `tools/test-ppt-scanner.cjs` は、隔離したChromiumプロファイルに拡張機能を読み込み、動画キャプチャ、Hubのiframeへの受信、遅延読み込み、連打、エラーを確認します。`PLAYWRIGHT_MODULE` にPlaywrightのモジュールパスを指定できます。

`PPT_SCANNER_FIXTURE` に実際の動画フレームのPNGパスを指定すると、本番サイトのHub・ONNXモデルまで通して認識を確認します。テスト画像はGitHubに追加されず、ブラウザ内で処理されます。
